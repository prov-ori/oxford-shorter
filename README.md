## Запуск

Для этой GitHub-копии сначала выполните `npm run build`: файлы данных создаются из модулей перевода. Затем `npm start`. Vercel выполняет сборку автоматически и публикует папку `dist` согласно `vercel.json`. Зависимости для сборки не требуются. Исходный PDF не входит в репозиторий; он подключается в интерфейсе на устройстве пользователя.

Откройте опубликованный личный сайт либо запустите из этой папки `node tools/serve.mjs` и откройте `http://127.0.0.1:4173`. Можно открыть `dist/index.html` напрямую, но надёжная работа хранилища, проверки PDF и резервных копий рассчитана на HTTPS/localhost.

## Что работает

- Полная последовательность глав и вложенных разделов задаётся данными; пустые разделы сохраняют место в оглавлении.
- Статусы: ожидает перевода, черновик, переведено частично, сверено с PDF, клиническая редактура. Сверка с PDF не означает независимую клиническую редактуру.
- Отдельные показатели переведённого и прочитанного; для неполного оглавления процент относится только к добавленной части.
- Web Speech API: доступные русские голоса, локальные голоса первыми, скорость, пауза, продолжение, остановка, короткие речевые фрагменты и подсветка блока. При отсутствии русского голоса отображается пояснение. Реальный голос зависит от устройства.
- Конспект: подготовленные по переводу краткие тезисы (не текст авторов книги) и личные заметки; экспорт Markdown. Для частичного перевода и панель, и экспорт указывают точную границу тезисов.
- Доступную часть большого раздела можно отметить прочитанной отдельно; такая отметка не увеличивает число полностью прочитанных разделов. После добавления нового текста отметка требует обновления, а личные заметки сохраняются.
- Прогресс, последнее место, настройки и записи в localStorage. PDF и импортированная версия учебника в IndexedDB.
- Резервная копия JSON переносит заметки и прогресс. Она не содержит PDF или текст учебника. Для другого устройства отдельно подключите PDF и тот же пакет перевода.
- Обновление текста с увеличением revision снимает отметку прочтения этого раздела, сохраняя заметки.
- Импорт читает только данные и выводит текст через textContent; HTML из пакетов не исполняется.

## Добавление материала

`dist/data/book.js` содержит `window.STUDY_BOOK`. Переводы хранятся в модулях `content/translation-*.mjs`; сборщик `tools/build-book.mjs` явно подключает готовые партии. `translation-002.mjs` сохранён как предыдущая частичная версия и источник начальных блоков полной главы 1. После изменений выполнить `node tools/build-book.mjs`. Оглавление и переводы его заголовков находятся в `content/source-outline.json` и `content/outline-ru.tsv`. Увеличивайте revision книги в сборщике и revision каждого раздела, чей текст изменён. Стабильные идентификаторы разделов нельзя менять: к ним привязаны заметки.

Сборщик также выпускает `dist/data/book.json`: этот файл импортируется через «Материалы → Добавить пакет перевода». Каждое обновление содержит весь накопленный материал. Идентификаторы `chNN-sNN` соответствуют зафиксированному порядку основных разделов; подзаголовки добавляются внутри blocks, не меняя соседние идентификаторы.

Книга: schemaVersion=1, id=`shorter-oxford-psychiatry-8-ru`, revision, title, edition, source, outlineComplete, chapters, glossary. Пока PDF не прочитан, source=null и chapters=[]. После извлечения source содержит filename, sha256 и pageCount. outlineComplete=true ставится только после визуальной проверки всего оглавления.

Глава: id, title (русский), originalTitle (из PDF), sections в исходном порядке. Предисловие, приложения, библиография и другие части также могут быть узлами верхнего уровня, если они есть в PDF. Не угадывайте структуру по другому изданию.

Раздел: id, title, originalTitle, level (1–6; уровень вложенности), revision (от 1), status, source={pdfStart,pdfEnd,printedPages?}, blocks, summary. PDF-страницы считаются с 1; printedPages хранит исходные печатные номера отдельно. Не путать их с PDF-номерами.

Статусы `partial`, `translated` и `reviewed` требуют checkedAgainstSourceAt (дата реальной сверки) и кратких тезисов. `reviewed` дополнительно требует reviewedBy; этот статус нельзя ставить без клинической редактуры. `pending` не содержит текста или тезисов. `draft` явно показывает предупреждение и не включается в число проверенных переводов.

У `partial` обязательна coverage={pdfStart,pdfEnd,printedPages,through,next}: страницы именно переведённой части, текстовая граница и следующий исходный заголовок. source продолжает описывать **полный** раздел. Даже если граница перевода и конец раздела лежат на одной странице, статус нельзя менять на translated до завершения всего текста. isRead/stats.read учитывают только целые разделы; isPartRead/stats.partialRead — прочитанную доступную часть текущей revision. Оба используют ту же совместимую запись completed в резервной копии. При завершении раздела поднять revision, поставить translated и удалить coverage.

Блоки:

- paragraph/quote: {type,text}; heading: {type,text,level?:2..6}.
- list: {type,items:[строки],ordered?:true}
- table: {type,caption,headers:[строки],rows:[[строки]]}; число столбцов сохраняется.
- box: {type,title,blocks:[блоки]}; сохранять номер и заголовок исходной вставки.
- figure: {type,src:"assets/filename.png",alt,caption}; активы добавляются в dist/assets, подписи переводятся. Не заменять рисунок общими рассуждениями.

glossary: [{en,ru,note?}]. Он задаёт единые переводные соответствия терминов; не использовать автоматическую замену слов без контекста.

## Подготовка PDF и перевода

1. `python tools/extract_pdf.py <путь-к-PDF> --out tmp/source`. Скрипт только читает исходник и извлекает контрольную сумму, закладки и постраничный текст. Весь tmp исключён из публикации.
2. Визуально проверить оглавление и начало/конец разделов. Извлечение может нарушать порядок колонок, таблиц, надстрочных знаков; пустые страницы требуют OCR. Закладки не считаются доказательством полного оглавления.
3. Перенести полную структуру в главы и разделы с pending. Начать перевод с первого содержательного раздела, сохраняя предисловия и служебные части в порядке книги.
4. Переводить завершёнными небольшими разделами без пересказа. Сохранять все абзацы, списки, оговорки, числа, единицы, таблицы, подписи, перекрёстные ссылки и библиографические указания. Не добавлять клинические утверждения от себя.
5. Сверить исходник и перевод по блокам. Проверить диагностические термины, шкалы, дозы, пути введения, ограничения и отрицания. Не обновлять утверждения книги по памяти; редакторские замечания, если нужны, отделять от перевода.
6. Добавить отдельные краткие тезисы, не заменяющие полный текст. Указать проверенные страницы, дату сверки, увеличить revision и проверить сайт. Каждая публикация сообщает точную границу переведённого материала.
